# 🤖 Customer Support Agent Bot

A smart AI assistant that classifies and responds to e-commerce customer queries using **LangGraph** and **Gemini 2.5 Flash**.

---

## 🚀 Features

- Auto classifies queries:
  - `order_status`
  - `return_policy`
  - `product_info`
  - `other`
- Uses Gemini for both classification and response
- Modular LangGraph routing logic
